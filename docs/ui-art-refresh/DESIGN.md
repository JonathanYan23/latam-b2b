# LATAM B2B — UI refresh

基线：`524cda1e5ec96ec536c18327b2447276d25db4d9`。分支：`feat/ui-art-refresh`。

## 设计方向

以采购和经营任务为中心：浅灰页面区分白色内容表面；深色文字突出商品、价格与关键数字；蓝色集中表达操作和当前导航；绿、橙、红保留状态语义。减少重阴影和无差别强调，保持原有三语含义与操作流程。

| 项目 | 规范 |
| --- | --- |
| 表面 | 页面 `#f6f7f9`，卡片 `#ffffff`，弱化面 `#edf0f4` |
| 文本 | 主色 `#202733`，次级 `#596577`，说明 `#687588` |
| 操作 | 蓝 `#245bd6`，悬停 `#1949b3`，选中底 `#edf3ff` |
| 排版 | Geist；正文 15px；说明 13px；标题响应式 26–32px；营销标题 32–60px；金额使用等宽数字 |
| 圆角 | 小元素 8px，输入与按钮 10px，卡片 16px，大表面 24px |
| 阴影 | 卡片细描边与极浅阴影，浮层使用原有 pop 阴影 |
| 间距 | 4/8/12/16/24/32/48/64px，移动内容侧边 16px |
| 响应式 | 门户 1024px 以下采用底栏；标签可换行；底栏与内容保留安全区 |
| 交互 | 明确 hover/focus/active/disabled；触屏数量控件至少 44px；遵循 reduced-motion |

## 实施范围

- `globals.css`：token、金额、按钮、输入焦点、表格反馈、触屏与减少动效；组件默认值置于 Tailwind components 层，避免压过页面 padding 等 utility。
- `portal-shell`、账户菜单、语言选择：当前页状态、平板导航、长标签、键盘焦点、触摸目标。
- 落地页：标题换行、留白、双角色入口和线性图标。
- 登录/注册：卡片表面、尺寸、模式切换与加载占位。
- 采购市场：搜索与筛选分组、商品标题/金额层级、图片分区、加购按钮。
- 零售与批发概览：经营数字层级和快捷操作布局。
- 管理端：导航换行、浅色页面表面。
- 错误和 404：统一状态面板。

其余页面继承共享样式；本批没有逐页重写全部详情页。导航匹配只修正当前项显示，URL 与业务行为保持不变。

## 发布边界

不修改数据库 schema、服务端 action、API、权限、价格计算、购物车队列或依赖。不合并 master，不部署。由 WorkBuddy 完整回归后决定合并。
